# ICM (Interpretable Context Methodology)

- routing/: routing table pointing to canonical locations
- clients/: per-client cards (status, next step, links)
- projects/: per-project cards (status, next step, links)
- references/: canonical references
- schema/: how notes are structured

Treat canonical docs (graphify-out/wiki, repo paths) as routing targets. Keep cards minimal; full narrative stays in canonical docs/notes.
