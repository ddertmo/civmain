# Fix report view link JavaScript quoting

- **Date:** 2026-10-15
- **Commit:** `HEAD`
- **Type:** fix
- **Areas:** Laravel web admin

## Problem
The report links generated by Monitoring and Pending Reports emitted unescaped single quotes inside their
JavaScript-rendered HTML, causing `Uncaught SyntaxError: Unexpected identifier 'cw'`.

## Changes
- Escaped the single quotes inside generated `onclick` session storage updates in `laravel/public/monitoring.html` and `laravel/public/pending-reports.html`.
