# Memory (P-A-R-A inspired)

- Inbox: capture unprocessed ideas/notes
- Projects: active work; each gets a hub note + dated session notes
- Areas: ongoing responsibilities (non-projects)
- Resources: Zettelkasten (one idea per note; use double-bracket links)
- Archive: completed/inactive

Practice: "one home per fact" — put each fact in exactly one canonical place; link rather than duplicate.
